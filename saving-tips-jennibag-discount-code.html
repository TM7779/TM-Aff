How to use the JenniBag discount code

  1. Select Show code above. The code is copied for you and JenniBag opens.
  2. Add what you want to your cart. Choose Classic or Roller Edition, and the color you want.
  3. Paste the code at checkout. Find the discount code box, paste PHAN and select Apply.
  4. Check the total before you pay. The discount shows as its own line in the order summary.

Want wheels? Compare the Signature

The Roller Edition of the JenniBag 2.0 costs $90 more than the Classic. The Signature, JenniBag's leather-look version with a flat garment compartment, is on sale, so its Roller Edition is $178: $40 less than the 2.0 Roller Edition.

When the Travel Bundle is worth it

The Travel Bundle adds the Vacuum Kit, Cosmetic Bag, Packing Cubes and Shoe Bag to a JenniBag. Bought separately with a Classic bag, that's $322; the bundle is $198. The bag and the Vacuum Kit alone come to $207, so if you'd buy those two anyway, the bundle costs less and the rest comes free.

Shipping and returns

JenniBag ships worldwide with carriers like FedEx, DHL and UPS, and advertises free shipping on its site; you'll see the cost for your country at checkout. Orders take 2 to 5 business days to leave the warehouse. You can return or exchange a bag within 30 days of purchase if it's undamaged and in its original packaging.

If the JenniBag code doesn't work

  • Compare with sale prices. Items that are already discounted may not take an extra code. If the code isn't accepted, compare the totals and keep the lower one.
