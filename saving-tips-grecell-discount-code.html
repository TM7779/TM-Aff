How to use the GRECELL discount code

  1. Select Show code above. The code is copied for you and GRECELL opens.
  2. Add what you want to your cart. Check the capacity in Wh, not only the wattage. The wattage says what it can power; the Wh says for how long.
  3. Paste the code at checkout. Find the discount code box, paste JAMESWICKENDEN and select Apply.
  4. Check the total before you pay. The discount shows as its own line in the order summary.
