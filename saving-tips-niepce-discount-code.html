How to use the Niepce discount code

  1. Select Show code above. The code is copied for you and Niepce opens.
  2. Add what you want to your cart. Niepce uses US sizes and says its unisex pieces are true to size. If you're between two sizes, it suggests the bigger one.
  3. Paste the code at checkout. Find the discount code box, paste JOVELAMY and select Apply.
  4. Check the total before you pay. The discount shows as its own line in the order summary.

For a refund, you're paid back to your original payment method or with a store gift card. For an exchange, tell Niepce the size you want and it ships the new one.
